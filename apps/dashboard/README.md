# Dashboard — Doctor & Admin (React + Vite + TS)

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run lint
npm run build
```

Skeleton only (Slice 1). TanStack Query + shadcn/ui + Tailwind, the live alert
feed, case view, and PHI-free admin KPIs are added in later slices. Roles/statuses
come from `@med/shared-types` (no magic strings).
